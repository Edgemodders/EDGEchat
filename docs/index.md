# EDGE<span class="y">plugin</span>

The EDGE plugin for Claude Code: Cyberpunk 2077 modding knowledge as skills, the EDGE MCP servers, and modding commands, in one install. Source: [github.com/Edgemodders/EDGEplugin](https://github.com/Edgemodders/EDGEplugin).

## Documents

| Document | What it covers |
|---|---|
| [Design](design.html) | Why a plugin, the facts from the Claude Code docs that shape it, its shape (MCP servers, skills, commands), where the knowledge comes from, sharing with REDagent, phases P0 to P5, the P0 decisions. Draft 0.2 |
| [Dev setup](dev-setup.html) | What a PC needs to build and test the plugin |
